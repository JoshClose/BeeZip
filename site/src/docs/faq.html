Questions and problems

Answers to what people run into most. If yours isn't here, ask on GitHub.

Windows says it protected my PC

That's the portable copy: until 1.0.0, its programs aren't signed, so Windows' SmartScreen doesn't know them yet and stops the first run. Choose More info, then Run anyway. On a PC with Smart App Control turned on, Windows blocks unsigned programs outright. BeeZip from the Microsoft Store is signed by Microsoft, so Windows runs it without asking, Smart App Control included.

The Microsoft Store copy is the one most people want. The portable copy is for running BeeZip without installing it, and the installer comes with 1.0.0:

The portable copy and the installer keep their settings in the same config.toml, so moving from one to the other keeps them. The Store copy uses that file too when it's there; on a PC that never had BeeZip, it keeps its own, which Windows removes with BeeZip (see Settings).

Install BeeZip one way: with the Store copy and another one's menu on the same PC, Explorer shows BeeZip twice. Settings → Explorer menu and beezip shell status point that out.

BeeZip isn't in the right-click menu

  • On Windows 11, with the portable copy, it's under Show more options. Windows 11's own menu needs a signed BeeZip: the Microsoft Store copy, or the installer from 1.0.0.
  • With the portable copy, the menu isn't added until you click Install in Settings → Explorer menu.
  • If it stopped working, for example after the portable copy's folder moved, click Repair there. beezip shell status says what's registered and what's wrong.
  • Some items are missing: they may be turned off in Settings → Explorer menu.

BeeZip says it doesn't read a file

BeeZip reads every format it lists itself, with no other program. A few files use something its readers don't, such as an ext volume over 16 TiB or an encrypted disk image, and BeeZip refuses them, saying what it found. Formats lists them. Since 0.6.0, BeeZip doesn't use 7-Zip for anything; a [seven_zip] section left in an older config.toml is ignored.

  • On Linux and macOS, an ESD image needs wimlib's library, which BeeZip loads to decode LZMS: apt install wimtools, dnf install wimlib or brew install wimlib (WIM and ESD).

BeeZip says my archive is damaged, but it isn't

7z and older RAR archives can't tell a wrong password from damage, so a mistyped password looks like damaged data. BeeZip asks again; check the password. If it's right and the archive still fails, beezip test names the damaged entries. A .bhive knows a wrong password from damage, and says which it is.

Which should I encrypt with: zip, 7z or .bhive?

A .bhive, when the people who open it have BeeZip 0.9 or later. It hides the files' names, dates and folders, notices any changed byte, makes each password guess take a gigabyte of memory, and can be opened with a key or a certificate instead of a password you have to pass on. A zip with AES-256 opens in most other archive tools, but leaves its names, sizes and dates readable, and its passwords are quick to guess at; ZipCrypto, for the oldest tools, is weak. A 7z hides its names but doesn't notice changed bytes. BeeZip keeps zip's and 7z's encryption as it is, for the tools that read them.

I've lost the password to a .bhive

Then only its other ways in can open it. If you made a recovery key, type it where the password goes, or under Recovery key in Unlock. If it was encrypted to one of your keys, or to a security key or This PC as well, that opens it. There's no other way in, for anyone, BeeZip included: that's what keeps it safe. Once it's open, Who can open this or beezip protect can give it a new password.

Why won't BeeZip let This PC be the only way in?

Because the archive would be lost with the PC. This PC's key lives in the PC's TPM and never leaves it, and Windows Hello works only on that PC too. If the PC breaks or is replaced, or Windows is installed again, an archive only they opened couldn't be opened anywhere. Add a password, a recovery key, a security key or someone's key beside them.

Does BeeZip work with my security key or smart card?

On Windows, BeeZip works with FIDO2 security keys that support hmac-secret, through Windows' own dialog, and with certificates whose private keys are on a smart card, through Windows' smart card support, which asks for the PIN. Neither has been tried on a physical device yet. If yours doesn't work, please say so on GitHub. On macOS and Linux, security keys and smart cards aren't supported; passwords, recovery keys, public keys and certificates in files (or the Keychain on macOS) are.

Are my archives safe from quantum computers?

A .bhive is when every way in is: passwords, recovery keys, security keys, Windows Hello and the post-quantum keys BeeZip makes (age1pq1…) are; classic age1… keys, certificates and This PC aren't. BeeZip says which in Protection, Who can open this and beezip protection. Your signing key is post-quantum too. Zip and 7z have passwords only.

The file names are garbled

The archive was made on a system that stored names in another code page, such as Japanese or Russian Windows. Choose its encoding: in the app, Name encoding in the command palette (Ctrl+K); on the command line, --name-encoding cp932 and the like. See Names from other systems.

Some files weren't extracted

BeeZip skips entries that would land outside the destination, links when they're off, and special files such as devices, and lists what it skipped and why. See Safety. Entries skipped because a file was already there follow your choice in the Extract dialog, or extract.overwrite.

I can't add to or delete from an archive

BeeZip changes zip, .bhive, 7z, tar, cpio and ar archives. RAR, CAB, packages, disk images, and split and self-extracting archives can't be changed; convert one to a format BeeZip writes first. A read-only file can't be changed either. The app says why when it can't.

Why are programs I extracted marked as downloaded?

Because the archive was. BeeZip copies a downloaded archive's Mark of the Web to what it extracts, as Explorer does, so Windows still checks those programs. extract.mark_of_the_web = "none" in Settings turns that off.

How do I update the portable copy?

When BeeZip finds a new version, its banner's Download gets the new zip. Close BeeZip and unzip the new version over the old folder. If you added the Explorer menu, click Repair in Settings → Explorer menu afterwards.

How do I remove BeeZip?

  • BeeZip from the Microsoft Store: right-click it in Start and choose Uninstall, or use Settings → Apps in Windows. Its menu, beezip and file types go with it.
  • The installer's BeeZip: Settings → Apps in Windows. It removes the menu, PATH entry and registrations, and leaves your file types as they were.
  • The portable copy: remove the Explorer menu first (Settings → Explorer menu → Remove, or bin\beezip.exe shell uninstall), then delete the folder.
  • Settings stay in config.toml (see Settings) until you delete it, except a Store copy's own file, which Windows removes along with BeeZip.

Something's wrong

Please open an issue on GitHub with what you did, what happened, and BeeZip's version (About, or beezip version). A job's Copy button puts its result and its whole log on the clipboard, ready to paste.
