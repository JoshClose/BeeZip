Questions and problems

Answers to what people run into most. If yours isn't here, ask on GitHub.

Windows says it protected my PC

Until 1.0.0, BeeZip's programs aren't signed, so Windows' SmartScreen doesn't know them yet and stops the first run. Choose More info, then Run anyway. On a PC with Smart App Control turned on, Windows blocks unsigned programs outright; wait for the signed 1.0.0, or build BeeZip yourself.

Portable copy or installer?

Until 1.0.0 there's only the portable copy. After that, the installer is the one most people want:

Portable copyInstaller
Installs anythingNo: runs from its folderYes, for you alone, without admin rights
Right-click menuClassic, under Show more options, if you add itWindows 11's own menu
Opens archives on double-clickNoYes, offered for the types BeeZip reads
beezip on PATHNo: bin\beezip.exe in its folderYes
UpdatesTells you, and links to the new zipInstalls them, when you click

Both keep their settings in the same config.toml, so moving from one to the other keeps them.

BeeZip isn't in the right-click menu

  • On Windows 11, with the portable copy, it's under Show more options. Windows 11's own menu needs the signed installer, from 1.0.0.
  • With the portable copy, the menu isn't added until you click Install in Settings → Explorer menu.
  • If it stopped working, for example after the portable copy's folder moved, click Repair there. beezip shell status says what's registered and what's wrong.
  • Some items are missing: they may be turned off in Settings → Explorer menu.

BeeZip says it doesn't read a file

BeeZip reads every format it lists itself, with no other program. A few files use something its readers don't, such as an ext volume over 16 TiB or an encrypted disk image, and BeeZip refuses them, saying what it found. Formats lists them. Since 0.6.0, BeeZip doesn't use 7-Zip for anything; a [seven_zip] section left in an older config.toml is ignored.

  • On Linux and macOS, an ESD image needs wimlib's library, which BeeZip loads to decode LZMS: apt install wimtools, dnf install wimlib or brew install wimlib (WIM and ESD).

BeeZip says my archive is damaged, but it isn't

7z and older RAR archives can't tell a wrong password from damage, so a mistyped password looks like damaged data. BeeZip asks again; check the password. If it's right and the archive still fails, beezip test names the damaged entries.

The file names are garbled

The archive was made on a system that stored names in another code page, such as Japanese or Russian Windows. Choose its encoding: in the app, Name encoding in the command palette (Ctrl+K); on the command line, --name-encoding cp932 and the like. See Names from other systems.

Some files weren't extracted

BeeZip skips entries that would land outside the destination, links when they're off, and special files such as devices, and lists what it skipped and why. See Safety. Entries skipped because a file was already there follow your choice in the Extract dialog, or extract.overwrite.

I can't add to or delete from an archive

BeeZip changes zip, 7z, tar, cpio and ar archives. RAR, CAB, packages, disk images, and split and self-extracting archives can't be changed; convert one to a format BeeZip writes first. A read-only file can't be changed either. The app says why when it can't.

Why are programs I extracted marked as downloaded?

Because the archive was. BeeZip copies a downloaded archive's Mark of the Web to what it extracts, as Explorer does, so Windows still checks those programs. extract.mark_of_the_web = "none" in Settings turns that off.

How do I update the portable copy?

When BeeZip finds a new version, its banner's Download gets the new zip. Close BeeZip and unzip the new version over the old folder. If you added the Explorer menu, click Repair in Settings → Explorer menu afterwards.

How do I remove BeeZip?

  • The installer's BeeZip: Settings → Apps in Windows. It removes the menu, PATH entry and registrations, and leaves your file types as they were.
  • The portable copy: remove the Explorer menu first (Settings → Explorer menu → Remove, or bin\beezip.exe shell uninstall), then delete the folder.
  • Settings stay in config.toml (see Settings) until you delete it.

Something's wrong

Please open an issue on GitHub with what you did, what happened, and BeeZip's version (About, or beezip version). A job's Copy button puts its result and its whole log on the clipboard, ready to paste.
