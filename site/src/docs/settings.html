Settings

BeeZip keeps its settings in one file, config.toml, which the app, Explorer's menu, the command line and the MCP server all read. Change it from the app's Settings, with beezip settings, or in any text editor.

Where the file is

SystemFile
Windows%APPDATA%\BeeZip\config.toml
Linux~/.config/BeeZip/config.toml
macOS~/Library/Application Support/BeeZip/config.toml

The environment variable BEEZIP_CONFIG names another file instead. Until you change a setting there's no file, and BeeZip uses the defaults below.

Changing settings

  • In the app: Settings (Ctrl+,) saves each setting as you change it, keeping the file's comments. A value BeeZip can't take shows its error beside the field, and isn't saved. The app's next job uses the new settings.
  • On the command line: 
    beezip settings get                                        # every setting, with its value
beezip settings set extract.overwrite=rename levels.zstd=19
beezip settings set "mcp.roots=['C:\Users\you\Unpacked']"
beezip settings set --reset limits.max_ratio               # back to the default
    A value is TOML (19, false, ['C:\a']), or a bare word for a string. Nothing is written unless the whole file still reads: an unknown key or a value of the wrong type is refused.
  • In an editor: other BeeZip programs read the file when they start. An unknown key only warns; a value of the wrong type stops every command until it's fixed, and the error gives the line.

Options on the command line, and choices in a dialog, override these defaults for that one job.

Extracting

SettingDefaultWhat it does
extract.overwrite"ask"A file that's already there: ask, always replace it, never replace it, rename the new one to name (1).ext, or replace it only if the entry is newer. Where nobody can be asked, ask fails.
extract.linksfalseMake symbolic links, ones that stay inside the destination. Hard links always come out as copies.
extract.mark_of_the_web"all"all copies a downloaded archive's Mark of the Web to every file extracted from it, as Explorer does (on macOS, its quarantine, as Archive Utility does). none doesn't. See Safety.
extract.threads0Threads for extracting zips and decoding xz. 0 is one per core, 1 uses one.

Changing archives

SettingDefaultWhat it does

Creating

Compression levels

levels holds a default level for any compressor or method: a compressor such as zstd, xz or gzip, a zip method such as deflate, or a 7z method such as lzma2. Each one you leave out uses its own default; beezip formats lists every range and default.

[levels]
zstd = 19
deflate = 9
lzma2 = 7

Names

SettingDefaultWhat it does
names.encoding"auto"How names stored as bytes are read: older zips, tar, cpio, ar, LHA, ARJ, ACE, ZOO, ARC, squashfs, CAB and ISO names. auto reads a name as UTF-8 when it is, and otherwise in the system's code page. Name a code page, such as cp932 or cp866, to read archives from another system. See Names from other systems.

Limits

These stop zip bombs and runaway archives. A job that reaches one stops, and says which.

SettingDefaultWhat it does
limits.max_ratio10000The most an entry may expand: its unpacked size over its packed size.
limits.max_entries10000000The most entries an archive may hold.
limits.decoder_memory_mib1024The memory, in MiB, a decoder may use for its dictionary or window.
limits.max_total_bytesnoneThe most one job may write, in bytes. Left out, there's no limit.

7-Zip

SettingDefaultWhat it does
seven_zip.enabledtrueUse an installed 7-Zip for the formats BeeZip reads through it.
seven_zip.pathnoneThe 7-Zip program to use. Left out, BeeZip looks in the registry, on PATH and in Program Files. It needs 7-Zip 25.01 or newer.

In the app, Settings → 7-Zip shows the 7-Zip BeeZip uses, where it found it, and its version. When there's none, or it's older than 25.01, Install 7-Zip or Update 7-Zip beside that installs it with winget (more). With a path set here, or 7-Zip turned off, the button doesn't show: installing wouldn't change which 7-Zip BeeZip uses.

The MCP server

SettingDefaultWhat it does
mcp.roots[]The folders beezip mcp may write in. With none, an assistant can read archives but not extract, create or change anything. --root replaces this list.
mcp.read_onlyfalseOffer only the tools that don't write.

MCP clients can't see or change these settings: one that could change mcp.roots could widen its own sandbox. See AI assistants.

The desktop app

SettingDefaultWhat it does
desktop.theme"system"system follows Windows' light or dark mode; light and dark stay put.
updates.checktrueLook for a new version on GitHub, at most once a day. The command line and the MCP server never check.

A whole file

[extract]
overwrite = "rename"
mark_of_the_web = "all"

[levels]
zstd = 19

[limits]
max_ratio = 20000

[shell]
cascade = true
[shell.items]
test = false
add-tar-zst = false

[mcp]
roots = ['C:\Users\you\Unpacked']

[desktop]
theme = "dark"
