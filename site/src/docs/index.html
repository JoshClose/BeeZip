Getting started

BeeZip opens archives in its own window, from Explorer's right-click menu, on the command line, and for AI assistants. This page gets you from the download to your first extracted archive, and points to the rest.

Install BeeZip

Get the file for your system from the download page.

  • Windows, the portable copy: unzip BeeZip_version_x64-portable.zip anywhere and run BeeZip.exe. Nothing is installed. Until 1.0.0, Windows asks before the first run, since BeeZip isn't signed yet: choose More info, then Run anyway.
  • Windows, the installer (from 1.0.0): run it. It installs for you alone, with no admin rights, and adds BeeZip to Windows 11's own right-click menu, to the archive types it opens, and to your PATH.
  • Linux: install the deb or rpm package, or run the AppImage.
  • macOS on Apple silicon: drag BeeZip from its disk image to Applications, then choose Open Anyway in System Settings › Privacy & Security the first time.

The download page has the details for each.

Open your first archive

  1. Start BeeZip and drop an archive on its window, or press Ctrl+O and choose one. Once BeeZip is installed, double-clicking an archive opens it too.
  2. The archive opens in a tab: its folders on the left, the entries in the middle, and a preview of the selected file on the right. Double-click a folder to go into it, and Backspace to come back out.
  3. Click Extract all, or select some entries first and click Extract. Choose where the files go, and click Extract.

The jobs list at the bottom shows the progress. If the archive is encrypted, BeeZip asks for the password; if a file is already there, it asks what to do.

The desktop app covers the rest: making archives, adding and renaming files inside them, dragging files out, and more.

From Explorer's right-click menu

Right-click an archive in Explorer, open BeeZip, and choose Extract here or Extract to "name\". A small window shows the job, and closes when it's done. Right-click files or folders and choose Add to "name.zip" to make an archive of them.

  • With the installer, the menu is already there, in Windows 11's own menu.
  • With the portable copy, add it from BeeZip: open Settings (Ctrl+,), go to Explorer menu and click Install. On Windows 11 it's under Show more options. It runs BeeZip from the portable copy's folder, so remove it there before moving or deleting that folder.

Explorer's menu lists every item and setting.

On the command line

The command line is beezip. The installer and the Linux packages put it on your PATH; in the portable copy it's bin\beezip.exe, and on macOS it's inside the app (the download page shows how to link it).

beezip list backup.zip              # what's inside, one folder at a time
beezip x backup.zip -o out          # extract into out
beezip c photos.7z Pictures         # make a 7z of a folder
beezip test backup.zip              # check every entry

The command line walks through the everyday commands, and the command reference lists every option.

Disk images, installers and 7-Zip

BeeZip reads and writes the common formats itself, and reads disk images and virtual disks such as VHDX and VMDK, their FAT, NTFS, ext, HFS+ and APFS file systems, WIM images, MSI and NSIS installers, CHM help files and CramFS images too. If 7-Zip 25.01 or newer is installed, BeeZip also opens the few files it doesn't read itself. It finds 7-Zip on its own; there's nothing to set up. Formats lists them.

Build it yourself

BeeZip is open source. To build it you need Rust (the toolchain the repository pins installs itself), Node 24 with pnpm, and Tauri's prerequisites: WebView2 and the MSVC build tools on Windows, WebKitGTK 4.1 on Linux, Xcode's command-line tools on macOS.

git clone https://github.com/JoshClose/BeeZip
cd BeeZip
cargo build --workspace             # the command line: target/debug/beezip
cargo xtask dist                    # the installer and the portable zip, or Linux's
                                    # and macOS's packages, under target/dist

The README covers the tests, running the app while you change it, and signing.
