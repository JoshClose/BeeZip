The portable copy

Unzip it anywhere (right-click it and choose Extract All) and run BeeZip.exe. Nothing is installed. The command line is bin\beezip.exe, and Settings → Explorer menu adds the right-click menu. The README.txt inside says how to update it.

Until BeeZip 1.0.0, its programs aren't signed, so Windows asks before the first run. Choose More info, then Run anyway.

The installer, from 1.0.0

It installs BeeZip for you alone, with no admin rights. It adds BeeZip to Windows 11's own right-click menu, offers it for the archive types it opens, puts beezip on your PATH, and updates itself.

What it needs

  • Windows 10 or 11, 64-bit, with the WebView2 runtime, which both have.
  • Optionally 7-Zip 25.01 or newer, to open WIM images, MSI installers and disk images such as VHDX. BeeZip doesn't come with it, but installs it with winget when you click Install 7-Zip (more).

The packages

Install the one your system takes. Each installs the app as beezip-desktop and the command line as /usr/bin/beezip, and offers BeeZip in the file manager's Open With for the archives it reads.

sudo apt install ./beezip_*_amd64.deb      # Debian, Ubuntu
sudo dnf install ./beezip-*.x86_64.rpm     # Fedora

The AppImage

Runs as it is, without installing, on a desktop with GTK:

chmod +x beezip_*_amd64.AppImage
./beezip_*_amd64.AppImage

What it needs

  • 64-bit x86 with glibc 2.35 or newer: Ubuntu 22.04, Debian 12 and later.
  • Optionally 7-Zip 25.01 or newer, for the formats read through it: 7-Zip's own 7zz from 7-zip.org, since distributions' packages are usually older.

Installing

Open the disk image and drag BeeZip to Applications.

BeeZip isn't signed with an Apple Developer ID, so the first time, macOS won't open it. Open System Settings › Privacy & Security and choose Open Anyway.

The command line is inside the app. To type beezip anywhere, link it into your PATH:

sudo ln -s /Applications/BeeZip.app/Contents/MacOS/bin/beezip /usr/local/bin/beezip

What it needs

  • A Mac with Apple silicon, on macOS 11 or newer.
  • Optionally 7-Zip 25.01 or newer (7zz, from 7-zip.org), for the formats read through it.

Checking a download

GitHub lists each file's SHA-256 checksum on its release page. To compare it with the file you downloaded:

Get-FileHash BeeZip_*_x64-portable.zip     # Windows, in PowerShell
sha256sum beezip_*_amd64.deb               # Linux
shasum -a 256 BeeZip_*_aarch64.dmg         # macOS
